# VSCode Icons assets

These SVG assets come from the VSCode Icons project by Roberto Huertas and
contributors. They are bundled locally so the SFTP file list does not need a
network connection at runtime.

- SVG Repo collection: https://www.svgrepo.com/collection/vscode-icons/
- SVG Repo author page: https://www.svgrepo.com/author/vscode-icons/
- Official upstream: https://github.com/vscode-icons/vscode-icons
- License: MIT; see `LICENSE.txt` in this directory.

Local filenames are normalized application names for the corresponding
`file_type_*.svg` assets. Most copies were obtained from the SVG Repo
collection; `cert.svg`, `php.svg`, and `video.svg` were obtained from the
official upstream repository when the SVG Repo mirror was rate limited.

Included categories:

- Generic: `default-file`, `default-folder`, `text`, `binary`, `config`
- Code and data: `c`, `cpp`, `csharp`, `css`, `html`, `java`, `javascript`,
  `json`, `php`, `powershell`, `python`, `shell`, `sql`, `toml`, `typescript`,
  `xml`, `yaml`
- Documents: `excel`, `markdown`, `pdf`, `powerpoint`, `word`
- Media and packages: `archive`, `audio`, `image`, `svg`, `video`
- Infrastructure and security: `database`, `docker`, `cert`
